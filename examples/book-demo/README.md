H. G. Wells's *The Time Machine* (1895), from
[Project Gutenberg](https://www.gutenberg.org/files/35/35-h/35-h.htm#chap05).

as a new longer check after the stable-cut policy was fixed. Original typography
and paragraph separation are preserved; HTML line wrapping is normalized.
